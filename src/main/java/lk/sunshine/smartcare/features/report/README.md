# Reports and analytics
Owner: Adassuriya A.V (IT25103522). Operational reports and PDF/XLSX exports. Revenue is explicitly simulated.

Report types: operations summary, doctor revenue by appointment branch, gross simulated demo-card revenue, and refund/cancellation rates. All accept date, doctor, and branch filters. See `docs/report-use-cases.md`.

The refund/cancellation report uses booking dates and lists matching cancelled appointments; other reports use scheduled visit dates.
